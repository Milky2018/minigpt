# Poetry Corpus Source

`poems_2m.txt` is derived from the Tang poetry JSON files in
`chinese-poetry/chinese-poetry`, specifically:

https://github.com/chinese-poetry/chinese-poetry/tree/master/%E5%85%A8%E5%94%90%E8%AF%97

Only poem paragraph text is included in the generated training corpus. Titles,
authors, rhythmic annotations, JSON field names, and source metadata are omitted
from `poems_2m.txt`.
