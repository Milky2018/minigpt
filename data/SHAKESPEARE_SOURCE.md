# Tiny Shakespeare Source

The default corpus is Andrej Karpathy's Tiny Shakespeare text, matching the
dataset downloaded by nanoGPT's `data/shakespeare/prepare.py`.

Source file:

```text
https://raw.githubusercontent.com/karpathy/char-rnn/master/data/tinyshakespeare/input.txt
```

This project stores the corpus as:

```text
data/tiny_shakespeare.txt
```
